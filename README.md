# 🎙️ PodStream — Podcast Platform UI

A modern, responsive podcast streaming platform interface built with HTML, CSS, and JavaScript. Designed to showcase a clean, intuitive listening experience with category-based episode browsing.

🔗 **Live Demo:** [ayesha-cs-93.github.io/Podcast-Platform-UI](https://ayesha-cs-93.github.io/Podcast-Platform-UI)

## ✨ Features

- **Navigation Menu** — Home, Discover, Favorites, and History sections
- **Trending Banner** — Highlighted featured podcast with quick-play access
- **Popular Episodes** — Curated episode cards organized by category (e.g., Web Development, Data Science)
- **Interactive Cards** — Click any episode card to play
- **Responsive Design** — Adapts smoothly across screen sizes

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
